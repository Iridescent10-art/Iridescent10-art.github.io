我的合法资源收藏夹：开源软件、免费字体与公共领域影视

旅行者2026-10-092026-10-09

收藏夹里攒了几年的「干净资源站」，今天整理成一篇。标准只有一个：要么是开源的，要么是明确授权免费使用的，全部可以放心给大家用，不存在版权风险。

先记住一句话：免费 ≠ 随便用。每一项都标了它的授权类型，文末附了一张速查表。

一、开源软件镜像站（国内下载加速）

装系统、装 Python 包、拉 Docker 镜像时最实用的四个，推荐按地理位置就近选：

镜像站 地址 特点
清华 TUNA https://mirrors.tuna.tsinghua.edu.cn/ 收录最全，文档也写得清楚
中科大 USTC https://mirrors.ustc.edu.cn/ 老牌镜像站，速度稳
阿里云 https://mirrors.aliyun.com/ 国内线路好，适合服务器
华为云 https://mirrors.huaweicloud.com/ 同上，偶尔有独占同步源

小提示：改 pip / npm / apt 源之前先确认发行版版本号，镜像站首页一般都有现成的一行命令。

二、开源软件与包管理

  • 代码托管：https://github.com/、https://gitee.com/（国内访问更稳）
  • Android 开源应用商店：https://f-droid.org/，只收录开源且可复现构建的 App
  • Linux 桌面应用：https://flathub.org/，一条命令装完，不用折腾依赖
  • Windows 包管理：https://chocolatey.org/，配合系统自带的 winget 用
  • 免安装便携软件：https://www.portableapps.com/，拷进 U 盘就能带走

三、免费可商用字体

做 PPT、剪视频、写推文最怕字体侵权，下面这些可以安心用：

字体 说明
Google Fonts 上千款开源字体，全部开源授权，网页引用首选
思源黑体 / 思源宋体 Adobe 与 Google 出品，SIL OFL，中文排版主力
霞鹜文楷 楷体风格，代码注释、手帐排版都好看
得意黑 标题字，瘦长有力，SIL OFL
阿里巴巴普惠体 / 站酷系列 官方声明免费商用，商用前扫一眼许可说明

四、图标与插画

  • 阿里巴巴矢量图标库 https://www.iconfont.cn/：中文场景最全，注意每个图标库的授权说明不一样
  • Lucide https://lucide.dev/、Heroicons https://heroicons.com/、Tabler Icons https://tabler.io/icons：三个都是 MIT 协议的现代图标集，写前端顺手就能用
  • unDraw https://undraw.co/：扁平插画，可以自己改主色，免费使用

五、图片、音效与 3D 素材

  • Wikimedia Commons https://commons.wikimedia.org/：公共领域与 CC 授权素材的宝库
  • Poly Haven https://polyhaven.com/：HDRI、模型、纹理，全部 CC0
  • ambientCG https://ambientcg.com/：材质贴图，CC0，做 3D 必备
  • Freesound https://freesound.org/：音效库，逐个看授权，有 CC0 也有 CC BY-NC

图片类素材还要注意一点：素材本身免费，但画面里的人物肖像、商标可能另有权利，商用前务必确认。

六、公共领域影视与音乐

  • Internet Archive https://archive.org/：老电影、老唱片、老游戏、旧书扫描件，规模惊人
  • IMSLP https://imslp.org/：公共领域乐谱库，古典乐手的老家
  • Musopen https://musopen.org/：公共领域古典音乐录音，配视频背景乐很好用

七、免费电子书与古籍

  • Project Gutenberg https://www.gutenberg.org/：五万多种公共领域电子书
  • 中文维基文库 https://zh.wikisource.org/：中文古籍、法律文本、公有领域作品
  • 中国哲学书电子化计划 https://ctext.org/zh：先秦到近代典籍全文检索，做研究很好用

八、免费学习平台

  • MIT OpenCourseWare https://ocw.mit.edu/：麻省理工公开课，讲义与作业全公开
  • 中国大学 MOOC https://www.icourse163.org/：国内高校课程，很多可以免费旁听
  • freeCodeCamp https://www.freecodecamp.org/：边做项目边学编程，全部免费
  • 可汗学院 https://www.khanacademy.org/：数学、科学基础课，讲得很细

附：授权速查表

标记 含义 能否商用
CC0 / 公共领域 作者放弃版权 可以，随便用
CC BY 署名即可 可以，需署名
CC BY-SA 署名 + 相同方式共享 可以，衍生作品要用同一协议
CC BY-NC 署名 + 非商业 不可以商用
CC BY-ND 署名 + 禁止演绎 可以商用，但不能修改
SIL OFL 开源字体协议 可以，通常禁止单独售卖字体本体
官方声明”免费商用” 作者自行授权 可以，注意附加条款

一句话原则：不确定就去查原始授权页，别信二手转述。

这份清单我会持续更新，遇到新的靠谱站点就补进来。也欢迎你把收藏夹里的好站分享给我。
