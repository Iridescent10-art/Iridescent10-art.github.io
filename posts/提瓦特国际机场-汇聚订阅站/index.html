提瓦特国际机场 全称：提瓦特七国国际航空枢纽暨天理统一航站楼。

七国的航班订阅，如今都收在同一个航站楼里。汇聚订阅站的入口是：

👉 https://dm.261024.xyz/explore

这一页由部署在 Cloudflare 上的订阅聚合与转换面板 MiSub 驱动（页脚显示的版本为 v2.7.0），它会把各家航线的订阅地址汇集起来、统一转换后再分发给旅客。下面按首屏从上到下的顺序，把页面内容完整介绍一遍。

一、航站楼大厅：机场自我介绍

打开链接后，最先看到的是「精选订阅」标签，紧接着是一行非常大的欢迎语：

原神启动！！！

✈️「提瓦特国际机场」✈️

标题下方是机场的官方简介，原文照录：

提瓦特国际机场 全称：提瓦特七国国际航空枢纽暨天理统一航站楼。位于璃月港与蒙德城之间的战略空域，承担蒙德、璃月、稻妻、须弥、枫丹、纳塔及至冬七国国际航班运输任务。机场采用风元素辅助起降系统，岩元素跑道维护技术，雷元素快速安检设备以及枫丹自主机械行李分拣系统。由于须弥学者大量前往枫丹参加学术会议，机场曾一度出现严重的知识分子航班延误现象。目前机场年旅客吞吐量约为 1.2 亿名旅行者，其中约有三分之一拒绝购买机场里的原石饮料。值机柜台：凯瑟琳。安检负责人：九条裟罗。机场广播：温迪。航空公司董事长：凝光。机场建设总顾问：钟离。机场财政状况：那维莱特表示不予置评。

简介块旁边还留了一个 原神官方网站 的入口，方便旅客随时回到提瓦特大陆的官方页面。右上角则是登录按钮、主题切换、语言切换与 GitHub 入口。

二、航班公告：机场正在例行维护

页面中段挂着机场的运行管理委员会公告，当前状态是 正在维护中：

尊敬的各位旅客：

由于提瓦特国际机场航站楼及七国跨境航空系统正在进行例行维护，目前机场暂时停止办理值机、安检、登机及行李托运业务。

公告里逐条列出了各个航站楼的维护项目：

公告末尾由「提瓦特国际机场运行管理委员会」署名，并注明「本公告最终解释权归天理维序机关所有」，页面底部显示最后更新时间为 2026/10/8 19:28:26。也就是说，这一段时间里订阅列表会暂时收起，等维护结束、机场重新开放值机后再回到常态。

四、怎么登机：三步走

  1. 打开航站楼：访问 https://dm.261024.xyz/explore，等「精选订阅」列表加载出来。
  2. 领登机牌：在列表里挑选需要的航线，复制它提供的订阅链接（部分入口需要登录后才会显示）。
  3. 登机出发：把订阅链接粘贴进上表任意一个客户端，更新订阅即可开始使用，之后的节点变更会自动同步。

如果只是想确认机场的运营状态、或者给新设备装客户端，这一页也够用；想看各个节点的实时负载，可以顺手移步到节点观测站。
