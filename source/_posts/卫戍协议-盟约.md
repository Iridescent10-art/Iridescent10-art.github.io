**卫戍协议：盟约（STRONGHOLD PROTOCOL: ALLIANCE）** 是一款跑在浏览器里的多人协作塔防游戏，原型来自《明日方舟》的「卫戍协议」玩法，由社区做成网页联机复刻版。它不需要安装任何客户端，打开链接、填一个博士代号就能直接开打，联机走的是房间制，最多 4 名博士合作。

## 玩法一句话

> 调配资金与干员，与同伴协同布防，抵御多波次进攻，直至击败敌方领袖。

进入游戏后会先来到「选择模拟协议」界面，这里要定三件事：

- **模拟方式**：`独立模拟`（自己一个人调配资金与干员，休整期与机变阶段不限时）或 `同盟模拟`（与至多 3 名博士共享干员池，联防阶段的生命值合并计算，可用 AI 队友补位）。
- **模拟难度**：从 `AC-1 标准模拟` 一路到 `AC-4 终极模拟`，回合数同为 14 回合，难度越高战场越随机、隐藏核心越多、奖励越丰厚。
- **加入同盟**：向同伴索取 4 位同盟密钥，或直接粘贴邀请链接加入现有房间；不想打也可以先「观战」。

![选择模拟协议界面](/img/stronghold-lobby.jpg "选择模拟协议：模拟方式、难度与同盟密钥")

正式开局之后就是卫戍协议的老味道：每一波敌潮之间有休整期，可以买干员、升级、摆阵；战斗阶段按干员职业与站位结算输出。干员晋级后已配发的装备会被回收，需要重新配置，这一点在界面右下角的「作战提示」里会反复提醒。

## 一些细节

- 全程网页运行，手机/平板横屏也可玩，支持全屏
- 界面提供中文 / English / 日本語 / 한국어 / 繁體中文 五套语言
- 右上角实时显示延迟（例如 429 ms），联机质量一眼可见
- 当前版本：`V0.2.1 · WEB SIMULATION`
- 这是**非官方同人复刻作品**，游戏素材版权归上海鹰角网络 / Yostar 所有

## 更新记录：我的部署命令

### vps 更新

```bash
cd /opt/Stronghold-Protocol && \
set -e && \
echo "===== 1. 拉取最新代码 =====" && \
git fetch origin && \
echo "===== 2. 停止 Stronghold =====" && \
systemctl stop stronghold && \
echo "===== 3. 同步到 origin/master =====" && \
git reset --hard origin/master && \
echo "===== 4. 当前版本 =====" && \
git rev-parse --short HEAD && \
node -p "require('./package.json').version" && \
echo "===== 5. 安装依赖 =====" && \
sudo -u stronghold npm ci && \
echo "===== 6. 执行 setup =====" && \
sudo -u stronghold node tools/setup.mjs && \
echo "===== 7. 启动 Stronghold =====" && \
systemctl daemon-reload && \
systemctl start stronghold && \
echo "===== 8. 等待服务启动 =====" && \
for i in $(seq 1 15); do \
  if curl -fsS http://127.0.0.1:3000/healthz >/tmp/stronghold-healthz 2>/dev/null; then \
    break; \
  fi; \
  sleep 1; \
done && \
echo "===== 9. 服务状态 =====" && \
systemctl status stronghold --no-pager -l && \
echo "===== 10. Healthz =====" && \
cat /tmp/stronghold-healthz && \
echo && \
echo "===== 更新完成 ====="
```

### nas 的 docker 更新

```bash
cd /vol1/1000/Docker/Stronghold-Protocol && \
git fetch origin && \
git reset --hard origin/master && \
chmod -R a+rX . && \
docker build --pull -t stronghold-protocol:nas --build-arg FETCH_ASSETS=1 . && \
docker stop stronghold 2>/dev/null || true && \
docker rm stronghold 2>/dev/null || true && \
docker run -d \
  --name stronghold \
  --restart unless-stopped \
  -p 3000:3000 \
  -e HOST=0.0.0.0 \
  -e PORT=3000 \
  -e SP_NO_BROWSER=1 \
  stronghold-protocol:nas && \
sleep 3 && \
docker ps --filter name=stronghold && \
curl -s http://127.0.0.1:3000/healthz
```
