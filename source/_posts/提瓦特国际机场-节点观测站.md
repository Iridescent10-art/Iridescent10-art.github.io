![提瓦特国际机场 · 节点观测站面板](/img/vps-panel.png "节点观测站首屏：全球节点观测 + 总览卡片 + 节点列表")

## 一、首屏：全球节点观测

页面打开后，主标题是 **全球节点观测**，副标题写着「DM🐣 的实时负载、资源占用与网络质量。」右侧同时给出三项核心状态：

| 指标 | 含义 |
| --- | --- |
| ONLINE 4 / 4 | 当前在线节点数与总节点数 |
| TRANSPORT WEBSOCKET | 数据推送方式为 WebSocket 长连接，属于秒级刷新 |
| TODAY COST ¥13.58 CNY | 今日产生的费用折算金额 |

## 二、总览卡片：一眼看完机场体检报告

主标题下方是六张总览卡片，分别汇总所有节点的内存、硬盘、流量与实时带宽：

| 卡片 | 面板上显示的内容 |
| --- | --- |
| 内存用量 | 3.2 GB / 10.5 GB，MEM 标签 |
| 硬盘用量 | 2.98 TB / 4.63 TB，DSK 标签 |
| 付款总额 | ¥474.99 CNY，VAL 标签 |
| 累计流量 | 372.0 GB，SUR 标签 |
| 实时上行 | 69 KB/s，UP 标签 |
| 实时下行 | 130 KB/s，DLR 标签 |

这些数字都是所有节点聚合后的结果，鼠标停留在卡片上还能看到更细的说明，不需要逐台服务器去登陆检查。

## 三、节点列表：每台航班一个座位

再往下是节点卡片列表，标题是「全部节点」（也可以先按地区筛选）。每张卡片给出节点名、地区旗帜、在线时长，以及 CPU 与内存的实时占用率：

- **US🐣RN** — 🇺🇸 美国节点，卡片上显示在线 2 天
- **JP🐣AC** — 🇯🇵 日本节点，卡片上显示在线 29 天
- **HK🐣AC** — 🇭🇰 香港节点，卡片上显示在线 17 天
- **NAS-iridescent10** — 🇨🇳 家里的 NAS，用来放观测站之外的个人服务

卡片顶部的「资源状态 / RESOURCE」区块会实时刷新 CPU 与内存占用，右侧的时区与地区图标则方便快速定位。右上角还有一组切换按钮，可以在卡片视图和更紧凑的列表视图之间切换。

后台登记的信息里，每台机器都带有 CPU 型号、虚拟化方式、系统版本、内核、价格与流量上限、到期时间等字段，所以面板侧边还能展开查看这些「飞机档案」。

## 四、右侧的地球：航线拓扑

首屏右侧那颗旋转的深色地球，是把节点按经纬度投影到球面上的实时连接图：光点代表节点，亮线代表连接。它和左侧的节点列表联动，用来看整体拓扑比翻列表直观得多。

## 五、这座塔台用来干什么

- **看在场情况**：哪个节点掉线、哪台机器负载飙高，首屏 ONLINE 与卡片颜色会立刻反映出来。
- **看流量水位**：累计流量与流量上限对比，避免月底突然断航。
- **看网络质量**：实时上下行带宽配合历史曲线，能判断线路是不是在抖动。
- **看账单**：付款总额、今日花费、到期时间都写在面板上，续费不会漏。
